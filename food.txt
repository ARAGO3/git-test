Git, git-hub : 코드와 데이터를 안전하게 보관하는 곳

Git : 파일관리, 형상관리툴, 인터넷에 연결되어있지않아도 파일관리해줌

맥에서 깃 설치하기

[Mac OS] 터미널에서 실행하기
> brew install git
> git config --global init.defaultBranch main
> git config --global init.defaultBranch
> git branch -M main
> git --version 넣고 설치 제대로 됐는지 확인하기

[windows OS]
> https://git-scm.com/
> 설치할때 override the default branch name for new repositories > main 작성
> git폴더 행성 > 우클릭 > open git banch here
> https://github.com/
